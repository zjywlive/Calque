# Example document

`tactile-gym-2.pdf` is used for the screenshots, the demo animation and the website.

- **Paper:** Yijiong Lin, John Lloyd, Alex Church, Nathan F. Lepora. *Tactile Gym 2.0: Sim-to-real Deep Reinforcement Learning for Comparing Low-cost High-Resolution Robot Touch.* arXiv:2207.10763, 2022.
- **Source:** https://arxiv.org/abs/2207.10763
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). The PDF is redistributed unchanged.
- **Changes:** the translated pages shown in this repository and on the website were machine-translated by Calque from the original. They are not endorsed by the authors.

Try it yourself:

```bash
/usr/bin/python3 -E cli.py examples/tactile-gym-2.pdf --to zh --mode dual --out examples/out
```
